Локальный триаж бесплатный. Jev получает текст задачи и возвращает уровень модели с уверенностью — для него нужен ключ выше.
Codex CLI работает по подписке Codex/ChatGPT через codex login. API-исполнитель не требует Codex: нужен только ключ или локальный сервер. Ручной исполнитель «ChatGPT (обычный чат)» вообще не тратит токены панели: промпт копируется в chatgpt.com, ответ вставляется сюда, а файлы, проверки, ревью и слияние остаются за оркестратором.
Обход через обычный ChatGPT не тратит токены панели: промпт появится в панели «Обычный ChatGPT · ответ вручную», ответ вставишь сам. Вариант «API-модель» работает без человека, но требует имя модели и ключ (или локальный сервер Ollama/LM Studio).
Ollama: http://127.0.0.1:11434/v1, LM Studio: http://127.0.0.1:1234/v1 — ключ не нужен. Для api.openai.com и openrouter.ai ключ обязателен.

GitHub, ветки и автоматическое слияние
По умолчанию безопасно: модель ничего не сливает сама. Автослияние включает только явный выбор и ключ Jev.
Этот контекст добавляется к каждой задаче только для выбранного репозитория и сохраняется в settings.json.
Codex всегда работает в отдельном worktree. Локальное слияние выполняется только fast-forward и только если исходная ветка не изменилась и checkout чист. Для GitHub используется ваш gh auth; write/push/merge происходит только автоматически после APPROVE Jev или после явной кнопки подтверждения. Jev получает ограниченный diff, сводку задачи, результаты проверок и ревью — не API-ключ.
